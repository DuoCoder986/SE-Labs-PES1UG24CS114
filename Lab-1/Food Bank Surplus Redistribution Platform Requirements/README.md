# Food Bank Surplus Redistribution Platform Requirements

This repository contains the software requirements, use case specifications, and UML diagrams for the **Food Bank Surplus Redistribution Platform**.

## Folder Structure

```
Food Bank Surplus Redistribution Platform Requirements/
├── README.md
├── requirements/
│   └── requirements-table.md
├── uml/
│   ├── use-case-diagram.png
│   └── use-case-diagram.puml
└── use-case-specification/
    └── generate-mock-server.md
```

## Description of Directory Contents

- **`requirements/`**: Contains the high-level functional and non-functional requirements table ([requirements-table.md](requirements/requirements-table.md)).
- **`uml/`**: Contains PlantUML source code ([use-case-diagram.puml](uml/use-case-diagram.puml)) and rendered image ([use-case-diagram.png](uml/use-case-diagram.png)) representing system use cases.
- **`use-case-specification/`**: Contains detailed use case specifications, such as [generate-mock-server.md](use-case-specification/generate-mock-server.md).
